## 为什么作废

这三份写在**红外链路打通之前**，因此包含大量后来被实测推翻的内容：

- ❌ 传感器用 DS18B20 / MAX30205 → 实际是**敏源 M601**（公式 `T = 40 + raw/256`），MAX30205 硬件损坏已放弃
- ❌ 上报走 WiFi + HTTP 云平台 → 实际走 **ESP-NOW 点对点**，不联网
- ❌ 手环自己联网校时 → 实测会改 WiFi 信道并切断 ESP-NOW，改为**由中枢经下行包下发时间**
- ❌ 红外模块 3.3V 供电 → 实测射程不足 1 米，**必须 5V**

**不要照着这三份文档去接线或写代码。** 保留它们只是为了记录"方案是怎么被实测修正的"——这个过程本身对参赛答辩有价值。
